# Console Snake 1.0

## Описание
Этот проект - змейка написанная на C++ и оформленная в коммандой консоли windows.

## Возможности
- сохранение прогресса
- настройка сложности игры
- смена внешнего вида игрока
- просмотр "званий" игрока
- подсчет рекорда

## Лицензия  
Этот проект распространяется без лицензии.
